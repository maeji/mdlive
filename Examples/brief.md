# 사용자 프로필 편집 화면 추가

## Goal
기존 설정 페이지에 사용자가 이름·소개·아바타를 수정할 수 있는 프로필 편집 화면을 추가한다.
현재는 프로필을 보기만 할 수 있고 수정할 방법이 없다.

## Context
- `src/pages/Settings.tsx` 아래에 탭으로 추가 (기존 탭 구조 재사용)
- 프로필 데이터는 `useProfile()` 훅으로 읽고, 저장은 `PATCH /api/profile`
- 폼 검증은 프로젝트 표준인 `react-hook-form` + `zod` 를 따른다

## Requirements
- [ ] 이름(필수, 2~20자), 소개(선택, 최대 200자), 아바타 이미지 업로드
- [ ] 저장 시 낙관적 업데이트 + 실패 시 롤백·토스트
- [ ] 변경 사항이 없으면 저장 버튼 비활성화

## Out of scope
- 비밀번호/이메일 변경 (별도 보안 플로우라 이번엔 안 함)
- 아바타 이미지 크롭/리사이즈 UI

## Acceptance criteria
- [ ] 이름을 비우거나 21자 이상이면 인라인 검증 에러가 보인다
- [ ] 저장 성공 시 프로필 화면에 변경 내용이 즉시 반영된다
- [ ] `PATCH /api/profile` 실패 시 원래 값으로 롤백되고 에러 토스트가 뜬다
